# EarthPulse

Explore how Earth's environmental conditions are changing using NASA
environmental data.

## Features
- NASA POWER environmental data
- Temperature, rainfall and solar analysis
- Theil–Sen trend estimation
- Mann–Kendall significance testing
- Interactive Earth visualization
- Location-based analysis
- Historical trend visualization

## Data
EarthPulse uses NASA POWER environmental data.

## How to Run

npm install
npm run dev
